# Native quit and Whisper Metal cleanup

AppKit Quit now cancels immediate native termination and dispatches the same
application action used by Settings and the tray. The existing save barrier
remains active on the normal event loop. Its terminal worker finalizes the
recording, joins the engine actor, then exits. Concurrent shutdown callers wait
for the same join; a second caller cannot exit while Metal resources remain alive.

## Verification

- `concurrent_shutdown_waits_for_actor_resources_to_be_released` failed before
  the mutex covered the join, then passed after the fix.
- `cargo test --manifest-path app/Cargo.toml -p souffle --test native_termination_main_thread`
  intercepted two actual AppKit `terminate:` calls, preserved the delegate
  instance, and reached its completion marker. No microphone or user profile.
- `SOUFFLE_QUIT_GPU_MODEL_DIR=<installed-whisper-directory> cargo test --manifest-path app/Cargo.toml -p souffle --lib loaded_whisper_actor_shuts_down_before_process_exit -- --ignored --nocapture`

  Apple M4 Pro Metal and 1623.92 MB of Metal weights, then exited with status 0.

  and concurrent join. Full workspace tests, fmt and clippy passed locally.
- The final combined sources at `107140d4` completed local CodeQL with exit
